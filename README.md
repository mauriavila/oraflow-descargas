# OraFlow

Git, Liquibase y bases de datos Oracle en una sola app de escritorio.

## Instalar (la primera vez)

**Paso 1.** En **Releases** (a la derecha) descarga el ultimo `OraFlow-x.y.z.zip`.

**Paso 2.** Descomprimilo y ejecuta `Instalar OraFlow.cmd`.

**Paso 3.** Listo: queda en el escritorio y en el menu Inicio.

Necesitas Windows 10 u 11 y Git instalado. No hace falta Python ni permisos de administrador.

## Actualizaciones

La app se actualiza sola: cuando hay una version nueva la descarga y te ofrece reiniciar.
